# Цель
Реализовать eq2 по прямой формуле (2.2) и показать её потерю точности.
Реализовать eq2_correct по формулам (2.3)–(2.4), устойчивым к вычитанию близких чисел.
Расширить устойчивое решение квадратного уравнения на комплексные корни.
Реализовать eq3 по формулам (2.6)–(2.13).
Проверить случаи с тремя действительными корнями кубического уравнения и с одной действительной и двумя комплексно-сопряжtнными корнями.

# Обработка особых случаев и ограничения
a=0 для квадратного уравнения означает, что уравнение не квадратное. Функции возвращают NAN; переход к линейному уравнению не выполняется.
D=0: два совпадающих действительных корня; D<0: их обрабатывает только комплексная версия.
Нулевые коэффициенты b, c обрабатываются без деления на ноль в устойчивом методе.
Для нечисловых/бесконечных коэффициентов (NAN, INFINITY) возвращаются NAN-корни. Консольный интерфейс дополнительно отвергает такие входные данные.
На произвольно экстремальных числах конечной точности гарантировать точность невозможно. Повышенная точность long double зависит от компилятора и платформы; на некоторых платформах она совпадает с double.
Базовая eq2 специально оставлена в виде из пособия, поэтому может терять точность и переполняться на больших коэффициентах. Для практических вычислений следует использовать eq2_correct / eq2_correct_complex.

# Тестирование
Тестовая программа tests.c вызывает функции напрямую — без ручного ввода. Для каждого теста сравниваются вычисленные и ожидаемые корни (порядок корней не имеет значения). Для кубических уравнений дополнительно проверяется подстановка всех найденных корней обратно в исходный многочлен.
Числа с плавающей точкой не сравниваются через ==: используется допуск. Для обычных корней он составляет примерно 1e-12–1e-13; для очень малого корня отдельно проверяется относительная ошибка 1e-12 и абсолютная 1e-40. Для невязок кубического уравнения применяется масштабированный допуск 1e-11.

Реализованы обе формулы для квадратного уравнения, расширение на комплексные корни и два случая решения кубического уравнения. 
Продемонстрирована численная неустойчивость формулы (2.2) и сохранение малого корня устойчивой формулой (2.3)–(2.4).
